# 数学自学台 · 考研数学个人自学网站

一个**完全在本机运行**的个人数学学习网站：课程、公式库、专项练习、错题本、复习计划、模拟考试、学习统计，全部功能都可用，没有装饰性空按钮。不需要账号、不需要云端数据库、不联网上传任何学习数据。

- 项目目录：`D:\Kaoyan-Project\math`
- **GitHub 源码**：https://github.com/x13502239474-oss/kaoyan-math
- **在线使用（GitHub Pages）**：https://x13502239474-oss.github.io/kaoyan-math/
- 技术选型：**零构建的静态单页应用**（原生 HTML/CSS/JavaScript + localStorage + hash 路由），无 npm 运行时依赖、无后端、无框架。手机端优先，支持 PWA 离线与添加到主屏幕。
- 数据规模：14 节课程 · 6 章 30 个知识点 · 50 条公式 · 52 道题（题干与答案解析分离存储）。

## 一、怎么启动（选一种即可）

### 方式 A：最简单 —— 双击 `index.html`
用 Chrome / Edge / Safari 直接打开，**所有学习功能都能用**，数据存在浏览器本地。
唯一区别：`file://` 下浏览器不允许注册 Service Worker，因此没有"离线安装 PWA"，但离线本身照样能打开使用。

### 方式 B：推荐 —— 双击 `启动网站.bat`
会自动查找 Python 并启动本地服务器，然后打开 `http://127.0.0.1:8080/`。
这个模式下 PWA 离线缓存生效，可"安装到主屏幕"。关闭那个黑色命令行窗口即停止服务。

### 方式 C：手机使用 —— 双击 `手机访问.bat`
手机与电脑连**同一个 Wi-Fi**，命令行窗口会打印一行 `From your phone: http://192.168.x.x:8080/`，在手机浏览器打开这个地址即可。
命令行参数等价写法：

```bash
python server.py              # 只监听本机，最安全（默认）
python server.py --lan        # 允许同一局域网的手机访问
python server.py --port 9000  # 换端口
```

> 端口被占用时换一个端口即可。服务器只提供静态文件，不收集、不上传任何数据。

### 方式 D：在线版 —— 任何设备直接打开

打开 https://x13502239474-oss.github.io/kaoyan-math/ 即可使用，手机浏览器里可「添加到主屏幕」，之后离线也能打开。这是 GitHub Pages 托管的**同一份静态源码**，无需电脑开机。

三点说明：

1. **数据互不相通**：学习记录存在「当前浏览器 + 当前域名」的 localStorage 里。本地 `file://`、`127.0.0.1`、局域网 IP 和这个在线地址是四份独立数据，不会自动同步；跨设备迁移请用「设置 → 导出 JSON」再在目标设备导入。
2. **公开但私密**：网站链接任何人可打开，但网站没有账号、没有后端、不上传数据，别人看到的只是一个空白的全新学习台，看不到你的任何记录。
3. **源码可自建**：仓库是公开的，也可 `git clone` 后按方式 A/B/C 在本机跑，或 fork 到自己账号下重新发布 Pages。
4. **`.nojekyll` 不要删**：GitHub Pages 默认用 Jekyll 构建，会跳过所有下划线开头的文件；本项目 `js/views/_common.js` 是公共渲染层，一旦被跳过线上就会白屏。根目录的 `.nojekyll` 用于关闭 Jekyll、按原样发布静态文件。其他三个科目网站若也部署到 Pages，同样需要这个文件。

## 四、内容与题库说明（重要）

> **本站不含任何历年真题、官方答案、教材原题或权威课程原文。**

- 内置 52 道题全部明确标注为 **「演示题」**（功能验证用）或 **「AI 生成练习题」**，题目卡片、解析页、练习配置页都会显示来源徽标与说明；导入的题目显示你填写的来源。
- 课程正文是**用自己的话重新组织的学习整理**，公式均为公共数学领域通用公式，不转录任何教材段落。
- 你提供的 10 份陈剑 / 朱曦系列 PDF（约 1.9 GB）经盘点均为**影印扫描版**，本机没有 OCR 引擎，无法逐页提取文字。因此本站**没有复制、没有转写这些资料的内容**，只参考管理类联考「数学基础」公开通行的章节体系（算术 / 代数 / 方程不等式 / 几何 / 数据分析 / 应用题）组织学习路径。
- 想把自己的教材、讲义、题目放进来，请用「设置与备份 → 批量导入」。**请只导入你有权使用的资料**，引用原文自行标注出处，避免大段照抄。

### 批量导入步骤
1. 打开 `templates/` 目录，参考 5 份模板：`导入模板-题目.json`、`导入模板-答案与解析.json`、`导入模板-课程.json`、`导入模板-公式.json`、`导入模板-例题解析.json`（设置页也能直接下载模板）。
2. 按模板填好内容，保存为 `.json`。
3. 在「设置与备份 → 批量导入教材内容」选择文件或粘贴 JSON，点「校验并导入」。
4. 导入结果会显示新增数量与逐条错误信息；导入内容可一键清空，不影响内置演示数据。

字段要点：
- 题目 `qtype` 只能是 `single / multi / judge / blank / essay`；`chapter` 用 `ch1~ch6`，`kp` 用知识点 id（如 `k25`）。
- **答案与解析可以单独导入**；如果直接写在题目对象里，系统会自动拆到 `answers` 表，保持题干与答案分离。
- 公式用受限 LaTeX：`$\frac{1}{2}$`、`$x^2$`、`$a_1$`、`$\sqrt{2}$`、`$\times$`、`$\le$` 等；在 JSON 里反斜杠要写成 `\\`。不支持 `\begin{cases}` 之类环境，用普通写法表达即可。
- 章节与知识点 id 见 `js/data/taxonomy.js`。

## 五、数据保存、备份与恢复

**存在哪里**：浏览器 `localStorage`，键名 `kaoyan_math_state_v2`。进度、笔记、公式收藏与掌握度、答题记录、收藏题目、错题本、复习计划、考试草稿与历史、活动记录、导入内容全部持久化。刷新页面、关闭浏览器都不会丢。每次写入前还会自动把上一版存到 `kaoyan_math_state_v2_prev`。

**重要限制**：数据跟着「浏览器 + 设备 + 访问地址」走。换浏览器、换电脑、清理浏览器数据、从 `file://` 换到 `http://` 都会看不到原来的数据。手机与电脑的数据各自独立（当前版本按你的要求不做云同步），迁移靠导出/导入。

**导出备份**
设置与备份 → 「导出 JSON 备份」，得到 `数学自学台-备份-YYYY-MM-DD-HHMM.json`。建议每周导出一次，放在网盘或另一块盘。

**恢复备份**
1. 设置与备份 → 「恢复备份」，选择文件（或粘贴 JSON 文本）。
2. 选模式：
   - **覆盖**：用备份完全替换当前数据（会二次确认）。
   - **合并**：把备份里本机缺少的记录补进来，本机现有记录优先。
3. 点「执行恢复」→ 确认 → 自动刷新。

备份文件带 `app: "kaoyan-math"` 校验，其他站的备份、损坏 JSON、结构不完整的文件都会被拒绝并提示原因。

**未来升级预留**：业务层只依赖 `App.Storage.read/write`，`App.Data` 统一提供"内置 + 导入"内容。以后要接后端/数据库，替换 `storage.js` 的实现即可，页面与判题逻辑不用改。

## 六、手机端与 PWA

- 响应式：≥900px 用左侧栏；<900px 自动切成**底部 5 项 Tab**（首页 / 课程 / 练习 / 错题 / 更多），全部次级功能收进「更多」。
- 无横向滚动（`overflow-x: hidden` + 弹性网格 + 公式区单独横向滚动）、按钮最小 44px 触摸目标、正文 15–16px / 行高 1.72。
- 公式使用**内置离线渲染器**（不依赖 MathJax/KaTeX/CDN），断网也能显示分数、上下标、根号与常用符号。
- PWA：在 `http://localhost` 或 `https` 下自动注册 `sw.js`（网络优先 + 断网回退缓存），支持"安装到主屏幕 / 独立窗口"。手机通过局域网 `http://192.168.x.x` 访问时，部分浏览器仍可用菜单「添加到主屏幕」，但浏览器可能不允许完整 PWA 安装（非安全上下文限制），这不影响使用。
- 更换源码后刷新即可生效（服务器发送 `no-store`，SW 也是网络优先）。图标可用 `python tools/make_icons.py` 重新生成。

## 八、常见问题

**Q：双击 index.html 后数据会丢吗？** 不会，但 `file://`、`http://127.0.0.1:8080`、`http://192.168.x.x:8080` 在浏览器里是不同来源，数据互不相通。请固定一种访问方式，或用导出/恢复迁移。

**Q：清理了浏览器数据怎么办？** 用之前导出的 JSON 恢复。没有备份则无法找回，所以请定期导出。

**Q：端口 8080 被占用？** `python server.py --port 9000`，或关掉占用程序。

**Q：手机上公式显示成乱码？** 本站公式不依赖外部字体库；若个别符号缺失，是系统字体问题，可换 Chrome / Safari 打开。

**Q：题目太少了？** 内置题目只是演示与功能验证。用批量导入把你自己的题库加进来，练习筛选、考试、统计都会自动纳入新题。

**Q：怎么和写作 / 逻辑 / 英语二网站保持风格一致？** 把本目录的 `css/tokens.css` 与 `STYLE_GUIDE.md` 复制给其他项目，四站共用同一套色板、圆角、间距、组件与导航结构即可。

## 九、技术说明（给以后接手的人）

- 所有 JS 都是普通 `<script>` + IIFE 挂到 `window.App`，**故意不用 ES module / 构建工具**，这样 `file://` 双击也能跑，同时源码仍按模块分文件、可版本管理、可用 Node `vm` 加载做单元测试。
- 状态变更统一走 `App.State.mutate()` → 自动 `save()` → 通知导航徽标刷新，避免各处手动写 localStorage。
- 路由是 hash 路由，不需要服务端 rewrite；`path()` 会剥离 query，所以 `#/practice?chapter=ch2` 这类深链接可用。
- Service Worker 采用**网络优先**，避免改了代码还拿到旧缓存；断网时回退缓存，`navigate` 请求回退 `index.html`。
